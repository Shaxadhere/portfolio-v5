# Shehzad Ahmed — Portfolio

A distinctive, animated portfolio built with Next.js, Tailwind CSS, and GSAP.

## Sections

- **Hero** — Name, title, city (Karachi, Pakistan), animated entrance
- **About** — Professional summary and key stats
- **Skills** — Technical stack with marquee animation
- **Experience** — Full work history from resume
- **Projects** — Featured project highlights
- **Contact** — Email, phone, resume download, education

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Deploy to Vercel, Netlify, or any static host. The resume is served from `/resume.pdf`.

```bash
npm run build
npm start
```

## Customization

Edit content in `src/data/portfolio.ts`. Styles and design tokens live in `src/app/globals.css`.
